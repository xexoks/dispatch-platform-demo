# Dispatch Platform Demo

Demostración técnica de una consola web para preparar despachos a partir de un evento georreferenciado.

## Objetivo

La aplicación permite registrar un evento mediante coordenadas o selección en un mapa y revisar información de apoyo para preparar una respuesta inicial.

## Flujo de la demo

1. Crear un evento mediante coordenadas o selección en mapa.
2. Normalizar y visualizar la ubicación del evento.
3. Consultar bases cercanas de demostración.
4. Mostrar distancia y rumbo respecto al evento.
5. Presentar tarjetas preparadas para análisis de recursos, meteorología y cobertura.

## Tecnologías

- React
- TypeScript
- Vite
- Node.js
- Fastify
- Zod
- PostgreSQL / PostGIS
- MapLibre
- APIs REST

## Alcance y seguridad

Este repositorio corresponde a una demostración independiente y usa exclusivamente datos simulados de prueba.

No incluye información operacional real, bases reales, personas, credenciales, claves, archivos `.env`, bases de datos, coordenadas sensibles ni datos de terceros.
